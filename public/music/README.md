# Holds indra local music

The inherited files are template listening samples, not music authored by void.
Replace them with your own or appropriately licensed audio before publishing:

- `track-01.mp3`
- `track-02.mp3`
- `track-03.mp3`

Optional artwork belongs in `artwork/` using matching names:

- `artwork/track-01.webp`
- `artwork/track-02.webp`
- `artwork/track-03.webp`

Update `data/music.ts` with the real title, artist, album, duration, and file paths.
The player never requires Spotify or an external music account.
